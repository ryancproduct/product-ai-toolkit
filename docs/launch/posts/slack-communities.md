# Slack Communities Post (Lenny's, Mind the Product)

Hey everyone — been working on something I thought this community might find useful.

I've built an open-source AI toolkit for PM work called **AI PM Kit**. It runs on Claude Code and includes 15 commands and 9 specialist agents, with deep integrations into Amplitude, Jira, Figma, Slack, and Confluence.

The key difference from generic AI tools: it uses real PM frameworks (Jobs-to-be-Done, Teresa Torres, INVEST) and grounds everything in your actual product data. No hallucinated metrics or made-up insights.

Quick example: run `/debate "Add a bulk actions feature"` and it spawns parallel Champion and Sceptic agents that pull from your analytics and issue tracker, then synthesise into a risk register, MVP scope, and go/no-go recommendation.

It's open source — figured this is more valuable as a shared resource than locked behind a paywall.
